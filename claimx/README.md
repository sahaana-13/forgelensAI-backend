# CLAIMX

AI-Powered Digital Accident Reporting & Insurance FNOL Platform.

This project is intentionally implemented with **React.js + FastAPI + MySQL + Gemini 2.5**, using normal CSS and real REST APIs. It starts from zero and includes authentication, role-based dashboards, accident SOS, GPS/timestamp capture, evidence uploads, private dual-party AI interviews, structured statements, neutral comparison, evidence consistency, missing information, claim readiness, FNOL generation, PDF export, notifications, and admin review.

See `server/README.md` for setup and demo credentials.
